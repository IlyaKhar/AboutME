# Портфолио - Ilyushechka Vey

Современное портфолио веб-разработчика с темной темой и интерактивными элементами.

## ✨ Особенности

- 🎨 **Современный дизайн** - Темная тема с желтыми акцентами
- 📱 **Полная адаптивность** - Оптимизирован для всех устройств
- ⚡ **Высокая производительность** - Быстрая загрузка и плавные анимации
- 🎯 **UX/UI** - Интуитивный интерфейс с кастомным курсором
- 🔗 **Интерактивность** - Кликабельные карточки портфолио

## 🛠 Технологии

- **HTML5** - Семантическая разметка
- **CSS3** - Современные стили с CSS переменными и анимациями
- **JavaScript** - Интерактивность и плавные переходы
- **Font Awesome** - Иконки
- **Google Fonts** - Типографика
